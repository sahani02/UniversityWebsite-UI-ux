# 🌍 University website– UI/UX Prototype

## 📌 Project Overview
This project is a UI/UX prototype of sample website for a university 

## 🎯 Objectives
- Provide an easy-to-use interface for students, staff and others
- Allow filtering by searching and navigate to LMS
- Improve user experience through clean design

## 🧩 Features
- Home Page
- About Us Page
- Contact Us Page
- Admission Page
- News & event Page
- Menu bar
- Search bar
- LMS Protal Login

## 🎨 Design Decisions
- Color Theme: Meroon,Gray, White, Black
- Typography: Poppins / Roboto

## 🛠️ Tools Used
- Axure RP
